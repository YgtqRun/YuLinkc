# M3 集成状态机验证记录（2026-09-08）

对应 `实现方案.md` 里程碑 M3：介质识别 + 双探活 + 认证窗口状态机 + 自动重登。

## 新增模块

| 模块 | 职责 |
|---|---|
| `network.rs` | GetAdaptersAddresses/GetBestInterface 识别默认路由介质（有线/无线）；HTTP 探活 |
| `auth_session.rs` | 一次完整登录会话：建认证窗口 → 注入脚本 → 等信标 → 销毁 |
| `inject.rs` | 注入脚本模板组装（从 POC 抽出） |
| `scheduler.rs` | 巡检循环：外网通→待命；外网断+认证页可达→自动登录；动态密码错误→作废提醒 |
| `state.rs` | 运行状态管理与 `yulink://status` 事件广播（UI 徽标联动） |
| `mock.rs` | mock 认证页服务（POC 与 E2E 共用） |

## 调度逻辑

- 在线巡检间隔 120s、离线 30s（配置可调）；
- 外网通 → `connected`；外网不通 + 认证页不可达 → `network-down`；
- 认证页可达 + 动态密码有效 → 自动登录；门户报动态密码错误 → 立即作废并提示补码；
- 登录成功后再做外网探测双确认（最多 3 次）；
- 托盘"立即登录"与界面按钮都会给调度器发即时触发消息；
- 介质判定：有线 → `.3`、无线 → `.2`（配置可改，E2E 可指向 mock）。

```powershell
$env:YULINK_MOCK_PORTAL="1"; $env:YULINK_E2E_SEED="1"; $env:YULINK_AUTH_VISIBLE="0"; npm run tauri dev
```
