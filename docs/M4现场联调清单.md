> `172.26.255.2/.3`，只能做 M1-M3 的 mock 验证。
>
> **选择器已确认**：认证页元素与 `登录脚本.js` 一致，第 1、2 步（抓页与 DOM

## 0. 准备

- 拉到最新代码，`npm install` 完成；
- 准备真实校园网账号与**电信动态密码**（短信下发，6 位数字）；
- 现场机器允许 WebView2（Win10/11 自带）；
- 联调期间认证窗口会**显示在屏幕**（debug 默认），便于观察填表与点击。

## 1. 抓取真实认证页 HTML

> ✅ 已确认跳过：选择器以 `登录脚本.js` 为准（即当前内置默认值）。

在校园网现场执行：

```powershell
cd D:\project\win\YuLinkc
.\scripts\save-portal-html.ps1
```

产物：`docs\portal-html\172.26.255.2-时间戳.html` 与 `.3` 同名文件（含 meta）。
若抓不到，先用浏览器打开 `http://172.26.255.2/` 手动另存为完整网页。

## 2. DOM 校准（最重要）

> ✅ 已确认跳过：`登录脚本.js` 指向的元素即真实页面元素，与内置默认值一致。

对比抓到的 HTML 与注入脚本选择器：

| 语义 | 默认选择器（可配置） |
|---|---|
| 表单根 | `#f1_div` |
| 账号框 | `#f1_div form input:nth-of-type(3)` |
| 密码框 | `#f1_div form input:nth-of-type(4)` |
| 运营商下拉 | `#f1_div select[name='ISP_select']` |
| 动态密码 | `#dynPass` |
| 登录按钮 | `#login_btn` |
| 结果消息 | `#message` |

默认值已参数化，存在配置文件的 `selectors` 节点：
`%APPDATA%\com.tauri-app.yulink\config.json`

```json
"selectors": {
  "root": "#f1_div",
  "account": "#f1_div form input:nth-of-type(3)",
  "password": "#f1_div form input:nth-of-type(4)",
  "isp": "#f1_div select[name='ISP_select']",
  "dynPass": "#dynPass",
  "login": "#login_btn",
  "message": "#message"
}
```

发现不一致 → 修改 config.json（或 [auth.js](../assets/auth/auth.js) 内置默认值）
后重启应用，不需要重新编译 Rust。

## 3. 首次登录（无线）

```powershell
cd D:\project\win\YuLinkc
npm run tauri dev
```

1. 托盘左键打开设置；
2. 填真实账号、密码、电信动态密码；
3. 点"保存"再点"立即登录"（或直接"立即登录"）；
4. 观察屏幕上认证窗口的填表/点击过程；
5. 期望状态徽标变绿 `已连接`；
6. 若失败，日志在 `%APPDATA%\com.tauri-app.yulink\logs\yulink.log`，
   会记录门户返回的错误文案（普通认证失败 vs 动态密码错误已分类）。

## 4. 有线验证

插网线重复第 3 步：调度器应识别为"有线"并选择 `172.26.255.3`。
介质判断依据日志里的"开始登录会话 -> http://172.26.255.x/..."。

## 5. 动态密码过期与补码

- 清空动态密码后触发登录 → 状态应为"需动态密码"，不发起无意义的登录窗口；
- 门户报"动态密码错误" → 程序立即作废该码并提示重新获取；
- 补码保存后再登录。

## 6. 断网自愈

1. 确认已连接；拔网线/断开 Wi-Fi；
2. 重连（或切换介质）；调度器默认 30s（离线）/120s（在线）巡检；
   想快速验证可先改 config.json 的
   `checkIntervalOfflineSec` / `checkIntervalOnlineSec`；
3. 期望日志出现 自动登录 → 已连接，无需人工操作。

## 7. 双网卡 / 虚拟网卡

- VMware/Tailscale/TAP 等虚拟网卡不应影响判断（默认路由介质为准）；
- 双网卡并存若行为异常，记录实际 `Get-NetAdapter` 状态，后续按方案
  增加"优先有线/手动指定"配置。

## 8. 结果记录

把现场结果写入 `docs\联调记录.md`：

- 抓到的 HTML 文件名与时间；
- 选择器是否需要调整及最终值；
- 无线/有线登录是否通过；
- 动态密码过期、补码、断网自愈是否通过；
- 异常现象与日志片段。

## 常见问题

| 现象 | 处理 |
|---|---|
| 日志 `input-not-found` | 选择器与真实 DOM 不一致，按第 2 步校准 |
| 状态停在"认证页不可达" | 确认当前连的是校园网认证前网络，不是外网热点 |
| 动态密码连续报错 | 确认短信是最新下发且未过期，必要时重新获取 |
| 登录成功但状态仍 failed | 外网双确认未通过；检查探活地址或 DNS |
