同时把 POC 的窗口/信标逻辑抽成正式模块。

## 新增模块

| 模块 | 职责 |
|---|---|
| `src-tauri/src/tray.rs` | 托盘图标：左键打开设置窗口；右键菜单：打开设置 / 立即登录 / 开机自启 / 退出 |
| `src-tauri/src/store.rs` | `%APPDATA%\com.tauri-app.yulink\config.json`；密码/动态密码经 DPAPI 加密（`dpapi:v1:` 前缀）后落盘 |
| `src-tauri/src/logger.rs` | `logs\yulink.log`，512KB 滚动、保留 3 份 |
| `src-tauri/src/bridge.rs` | 页面 → Rust 的 Image 信标回传监听（从 POC 抽出，供后续正式登录流程使用） |

## 行为说明

- 主窗口默认**启动隐藏**（`tauri.conf.json` `visible: false`），点关闭仅隐藏到托盘，进程常驻；
- 单实例：`tauri-plugin-single-instance`，二次启动会聚焦已有实例；
- 开机自启：`tauri-plugin-autostart`（HKCU Run），托盘菜单切换并同步持久化；
- 托盘"立即登录"目前打日志占位，等 M3 登录状态机接入；
- 配置默认值结构与 `实现方案.md` §11 一致；日志与配置文件均不写明文凭据。
