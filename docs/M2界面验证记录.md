# M2 Vue 设置界面验证记录（2026-09-08）

对应 `实现方案.md` 里程碑 M2：Vue 弹窗复刻油猴脚本，状态联动。

## 界面能力（src/App.vue）

- 账号 / 密码（明文切换）输入；
- 动态密码输入、清除、有效期状态文案（剩余天数/小时/分钟/已过期/永久）；
- 有效期下拉：1/3/9/18/27 小时、永久、自定义；
- 开机自启开关；
- 状态徽标：未配置 / 需动态密码 / 已就绪（颜色区分）；
- 保存、立即登录、清空数据（二次确认）。

## 命令层（src-tauri/src/commands.rs）

| 命令 | 作用 |
|---|---|
| `get_settings` | 返回设置视图（密码/动态密码解密后仅供自有界面使用） |
| `save_settings` | 保存账号或动态密码（DPAPI 加密落盘） |
| `clear_sms_code` / `clear_all` | 清除动态密码 / 全量清空 |
| `set_autostart` | 切换开机自启并同步托盘菜单与配置 |
| `login_now` | 校验配置就绪；实际登录引擎待 M3 接入 |

## 验证结果

- `vue-tsc --noEmit && vite build`：通过；
- `cargo check`：通过；
- 正常模式启动后日志出现"设置界面读取配置"，证明隐藏窗口下的
  前端 → Tauri IPC → Rust 配置读取链路已打通；
- 状态与配置加密复用 M1 store（DPAPI），命令层无明文落盘。

## 遗留

- `login_now` 为占位（提示"登录引擎将在 M3 接入"）；
- 状态仅根据配置就绪度计算；联网/断线状态机在 M3 加入。
